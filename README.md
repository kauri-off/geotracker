# Mock Walk

Рисуешь пешеходный маршрут на карте в браузере, нажимаешь Play, сервер на Bun раз в секунду пишет mock-координаты в телефон через adb. Geo Tracker на телефоне записывает это как обычную прогулку.

## Требования

- [Bun](https://bun.sh) 1.x
- `adb` из Android platform-tools в PATH
- Телефон с включённой USB-отладкой; Geo Tracker или любой другой трекер, читающий стандартные провайдеры

Сервер при старте и в интерфейсе явно сообщает, если adb не найден, телефон не подключён, не авторизован или offline.

## Запуск

```
bun run start          # http://localhost:3210
ADB_SERIAL=xxx bun run start   # если подключено несколько телефонов
```

Телефон: USB-отладка включена, mock-приложение не нужно, shell сам становится mock-провайдером.

```
bun test               # юнит-тесты геометрии и диагностики adb
```

## Как пользоваться

1. Клик по карте добавляет точку, точки тянутся, правый клик удаляет, клик по линии вставляет точку между соседними.
2. Скорость по умолчанию 5 км/ч. В таблице точек можно задать паузу на точке и скорость от этой точки до следующей.
3. Метрики: длина, общее время, время движения, паузы, средняя скорость, по каждому сегменту длина, азимут, время.
4. Превью: ползунок или ▶ с ускорением, белый маркер бежит по маршруту без телефона.
5. Сохранить, потом ▶ Играть. Жёлтый маркер это то, что отправлено на телефон, зелёное кольцо это то, что телефон реально подтвердил через dumpsys.
6. Запись в Geo Tracker стартуешь сам, до или сразу после Play.

## Надёжность и откат

- Пауза держит текущую точку и продолжает её слать, чтобы приложение не писало «Ждём GPS».
- Ползунок телефона перематывает t, resume продолжает с этого места.
- Stop останавливает тики, телефон остаётся на последней точке. Cleanup снимает mock-провайдеры и возвращает реальный GPS.
- Отвал adb: после трёх ошибок подряд сервер переходит в error, сохраняет t, и при включённом авто-продолжении ждёт телефон и сам продолжает с того же места, заново поднимая провайдеры.
- Падение или Ctrl+C сервера: прогресс лежит в `data/session.json`, при следующем открытии страницы появляется кнопка «продолжить оттуда».
- Если телефон 3 проверки подряд подтверждает точку дальше 15 м от отправленной, в панели красное предупреждение.
- Маршруты хранятся в `routes/*.json`, их можно править руками или копировать.

## Реализм

Дрожание позиции с низкочастотным шумом, разброс скорости, плавающая accuracy. Всё настраивается в карточке параметров, нули отключают.
